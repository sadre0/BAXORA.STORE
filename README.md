# BAXORA premium storefront starter

Open `index.html` to preview the storefront. `admin.html` is a local prototype admin for adding/deleting catalogue items in this browser.

IMPORTANT: The prototype admin uses localStorage only. It is NOT secure, does not sync across devices or visitors, and is not production-ready. Before public launch, connect secure owner authentication, a database, image storage, and server-side order handling. Product prices are intentionally shown as “Price on WhatsApp” until actual prices are provided.
